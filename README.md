# Sakan
01 | Project Name – اسم المشروع
SAKAN | سَكَن
Digital Real Estate Rental Platform – منصة رقمية محلية للبحث عن الوحدات السكنية للإيجار في مدينة الإسماعيلية.
02 | Project Idea – فكرة المشروع
سكن مشروع لمنصة رقمية مقترحة تربط الباحثين عن وحدات للإيجار بملاك العقارات والمكاتب العقارية، عبر عرض إعلانات منظمة تسمح بالمقارنة حسب المنطقة والميزانية ونوع الوحدة والمساحة وعدد الغرف، ثم التواصل مع المعلن للاستفسار أو طلب المعاينة.
الجمهور المستهدف: الطلاب المغتربون والباحثون عن سكن قرب الجامعة، والأفراد والأسر الباحثون عن إيجار مناسب، والملاك والمكاتب العقارية الراغبون في عرض وحداتهم.
نطاق المرحلة الأولى: الإيجار داخل مدينة الإسماعيلية. التوسع إلى محافظات القناة أو إضافة بيع العقارات خيارات لاحقة لم تُعتمد. حالة المشروع الحالية: مرحلة الدراسة والتخطيط؛ لا تُعرض خصائص المنصة المقترحة باعتبارها وظائف منفذة بالفعل.

4. KPIs – مؤشرات الأداء
5Ss	المؤشر / المستهدف المقترح	موعد القياس
Sell	50 إعلان إيجار نشطًا ومكتمل البيانات، وربط كل طلب تواصل بالإعلان المعني.	اليوم 90
Serve	إتمام 8 من 10 مشاركين مهمة البحث على نموذج قابل للاستخدام دون مساعدة مباشرة.	أول 30 يومًا

Sizzle	8 من 10 يفهمون طبيعة الخدمة ونطاقها؛ ووضوح الرسالة 4/5 أو أعلى.	قبل اليوم 60
